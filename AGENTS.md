# AGENTS

For any AI agent or model working in this vault that does not load `CLAUDE.md` by itself: an agent run through Claudian, another model in an Obsidian plugin, or anything else given this folder.

`CLAUDE.md`, beside this note, is the constitution for every model, not only Claude. Read it first and follow it for the whole session, then `System/State.md` (the current picture, one screen) and the last twenty lines of `System/Corrections.md`.

The five rules that cause the most damage when missed, repeated here only as a safety net (if this list and `CLAUDE.md` ever differ, `CLAUDE.md` wins):

1. If `conflict-files-obsidian-git.md` exists or a note has `<<<<<<<` lines, the vault is mid-merge: fix or report that first.
2. British English, no em dashes anywhere, no invented figures or status.
3. Nothing is sent, spent, published, merged, deployed or deleted without the operator's yes.
4. No git commands on this vault except `git log`, `git show`, `git rev-list` and `git check-attr`.
5. Current pages (State, Now, a project's "State at a glance") are overwritten when a fact changes; history goes in the build logs. End the session with `System/Playbooks/SESSION EXPORT.md`.
