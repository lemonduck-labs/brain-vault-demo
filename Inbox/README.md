# Inbox

Drop anything here: meeting notes, screenshots, a pasted email, a voice-note transcript. INGEST files it into the right note, logs what it did in the [[Run log]], and marks the file as processed in its frontmatter. It never deletes anything here.

Processed files stay in place until the operator answers the one-time question in [[Now]] about moving them to `Inbox/Processed/`.
